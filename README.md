# Glenn Mark Naelgas — Portfolio

Personal portfolio website for remote Collections, Accounts Receivable, Billing Support and Customer Service roles.

## Files
- `index.html` — the page
- `styles.css` — styling (light and dark mode)
- `script.js` — role switcher (Collections / AR / Billing / Customer Service)
- `assets/glenn-naelgas.jpg` — profile photo
- `resumes/` — tailored résumés in PDF, downloadable from the site

## Publish on GitHub Pages
1. Create a new public repository named `<your-username>.github.io` (or any name).
2. Upload all files from this folder to the repository root (drag and drop works).
3. Go to **Settings → Pages**, set Source to **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
4. Your site will be live in a minute or two at `https://<your-username>.github.io/` (or `https://<your-username>.github.io/<repo-name>/`).

## Direct links to a role
